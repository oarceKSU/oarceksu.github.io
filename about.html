About This Project

This project was created for my Intro to Web Development course to demonstrate a foundational understanding of how modern websites are built and how browsers interpret them. Throughout the site, I apply core concepts like HTML for structure, CSS for styling, and (in future milestones) JavaScript for interactivity, showing how these technologies work together to form a complete webpage. This specific website also explores what a web browser is and how it functions, including topics like the history of web browsing, and the foundations browser are built on that allow users to access the internet. It’s meant to show that I understand not just how to write code, but also how the web browser reads and interpets this data.
