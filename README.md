# The Web Browser

This IT 3203 assignment is a small research website about web browsers, including their history and how they work.

This project focuses on basic HTML and CSS. HTML provides the structure and content across several linked pages, using headings, paragraphs, lists, tables, links, and images. A shared CSS stylesheet adds simple visual styling and layout for the title, navigation, tables, and page sections. This first milestone demonstrates a basic understanding of These components and something to build on for future milestones. 

For this milestone I used the W3School tutorials to help build the intitial template and then also used the W3 template from assigment 2 as a guide to build my own website. The YouTube video provided a deeper understanding of what each line of code was doing and the live preview let me visually see every change before committing. 

Once I had the homepage built it was mostly just copy/pasting the template to the other pages and only changing a few items within the body.
