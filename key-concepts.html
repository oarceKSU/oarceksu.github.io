Key Concepts

Terms Definitions
Web Browser A web browser is a software application that retrieves, interprets, and displays web content from servers around the world. It acts as the intermediary between users and the internet, translating code into the webpages we can read and interact with. A browser is like a translator and tour guide combined. It communicates with websites on your behalf and presents the information in a way you can understand.
HTML Hypertext Markup Language provides the structure and organization of a webpage by defining elements such as headings, paragraphs, images, and links. Every webpage relies on HTML as its foundational framework. HTML is like the blueprint or frame of a house. It determines where everything belongs, even though it does not control how the house is decorated.
CSS Cascading Style Sheets control the visual appearance of a webpage, including colors, fonts, spacing, and layout. CSS separates presentation from content, making websites easier to maintain and adapt across devices. If HTML is the frame of a house, CSS is the paint, furniture, and interior design that make the structure visually appealing
JavaScript JavaScript adds interactivity, logic, and dynamic functionality to webpages. Features such as animations, interactive forms, live notifications, and online applications rely on JavaScript. JavaScript is like the electrical and automation system in a house. It makes things move, respond, and react when people interact with them.
HTTPS Hypertext Transfer Protocol Secure protects data exchanged between a user's browser and a website through encryption. This helps prevent sensitive information, such as passwords and credit card numbers, from being intercepted. HTTPS is like placing a letter inside a sealed envelope instead of sending it as a postcard that anyone can read.
URL A Uniform Resource Locator is the unique address used to locate resources on the internet. Browsers use URLs to find and access specific webpages, images, or files. A URL works like a street address. Just as a delivery driver needs an address to find a house, a browser needs a URL to find a webpage.
TCP Transmission Control Protocol is a communication protocol that ensures data is delivered accurately, completely, and in the correct order between devices. If information is lost during transmission, TCP requests it again. TCP is like sending a multi-page document through the mail and checking that every page arrives in the correct order before accepting delivery.
SSL/TLS SSL/TLS is a cryptographic security protocol that encrypts internet traffic and verifies a website's identity. Modern websites use TLS to establish trust and protect user data during online communication. SSL/TLS is similar to checking a person's government-issued ID before sharing confidential information and then speaking through a secure, private phone line.
