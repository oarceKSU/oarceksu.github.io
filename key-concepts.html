Key Concepts

Terms Definitions
Web Browser A web browser is a software application that retrieves, interprets, and displays web content from servers.
HTML Hypertext Markup Language is the language that defines the structure and content of a webpage.
CSS Cascading Styling Sheets is the styling language that controls the visual design and layout of a webpage.
JavaScript JavaScript is the programming language that adds interactivity, logic, and dynamic behavior to webpages.
HTTPS Hypertext Transfer Protocol Secure is the secure version of HTTP that encrypts communication using TLS.
URL A Uniform Resource Locator is the address that identifies the location of a resource on the internet.
TCP Transmission Control Protocol is a reliable transport protocol that ensures data is delivered accurately and in order between browser and server.
SSL/TLS Secure Socket Layer/ Transport Layer Security is a cryptographic protocol that encrypts web traffic and verifies server identity for secure browsing.
Tim Berners Lee Inventor of the World Wide Web and creator of the first web browser.
WorldWideWeb WorldWideWeb was the first web browser, built by Tim Berners‑Lee in 1990, capable of both reading and editing web pages.
Mosaic Mosaic was the first widely adopted graphical web browser, released in 1993, and helped popularize the modern web.
